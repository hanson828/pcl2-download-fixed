# 代码说明（PCL2PatchGUI.ps1）

单个 `.ps1` 文件：全部逻辑 + 界面，纯 PowerShell 5.1 + WinForms，不依赖任何第三方模块。

## 文件结构

```
PCL2PatchGUI.ps1        全部逻辑 + 界面
PCL2补丁工具.vbs          用 wscript 以隐藏窗口启动上面的 ps1，避免闪黑框
```

## 代码分块，按顺序读就行

### 0) 日志（v1.1.0 起）

| 函数 | 作用 |
|---|---|
| `Initialize-Log` | 建目录、按天开 `StreamWriter`（UTF-8 BOM、AutoFlush）、超 2 MB 轮转、写启动环境块 |
| `Write-LogFile` | 只写磁盘；writer 为 `$null`（目录不可写）时静默跳过 |
| `Add-Log` | 界面框 + 磁盘双写，一处调用两条腿都到 |
| `Add-LogError` | 界面显示一句话，磁盘再补异常类型、位置、堆栈 |
| `Close-Log` | `FormClosed` 里 Flush + Dispose，保证最后一行落盘 |

日志目录默认 `%LOCALAPPDATA%\PCL2PatchTool\logs`，可用 `-LogDir` 改；
写日志失败**不影响**打补丁流程，只是退化成一个只有界面的工具。

### 1) 常量区

| 变量 | 内容 |
|---|---|
| `$SigExact` | 原版里"假加载器"的精确 48 字节（含 413 版的 token） |
| `$SigLoose` | 同形状、但 Token 位用 `-1` 通配，用于别的编译产物兜底 |
| `$Replacement` | `7E 0F 04 00 04`（`ldsfld DlClientListLoader`）+ 43 个 `00`（nop） |
| `$KnownVersion` / `$KnownMd5` | 用来提示"文件与预期版本不一致" |

### 2) 工具函数

| 函数 | 作用 |
|---|---|
| `Find-PclExe` | 先查常见安装路径，找不到再按盘搜（`-Depth 4`） |
| `Find-Match` | 通配字节匹配，返回所有命中偏移（>5 处就放弃） |
| `Find-Patched` | 判断是否已打补丁：`7E 0F 04 00 04` 后面至少 43 个 `0` |
| `Get-PclInfo` | 版本号 / 大小 / MD5 / `.bak` 路径 |
| `Stop-PclIfRunning` | 检测 PCL2 是否在跑，弹窗问是否帮忙关掉 |

### 3) 三个动作

| 函数 | 行为 |
|---|---|
| `Do-Check` | 只读，刷新状态与底部信息 |
| `Do-Apply` | 备份（仅首次）→ 写入 → 回读校验 → 失败回滚 → 成功弹窗 |
| `Do-Restore` | 从 `.bak` 还原（二次确认） |

### 4) 界面

纯代码构造的 WinForms：标题、路径框 + 浏览、状态标签（红 / 橙 / 绿 / 蓝）、四个按钮、日志框、
底部 MD5。窗体 `Shown` 后自动找 PCL2 并跑一次 `Do-Check`。

## 改起来最常动的地方

- **换适配版本**：改 `$SigExact`、`$Replacement` 里的 token、`$KnownVersion`、`$KnownMd5`。
  token 怎么找见 [technical.md](technical.md)。
- **换配色 / 文字**：第 4 块，控件都是 `SetBounds` + 颜色，随便调。
- **日志时间格式**：`Add-Log` 里的 `Get-Date -Format 'HH:mm:ss'`。

## 踩过的坑

- 这个 `.ps1` 必须存成 **UTF-8 with BOM**，否则 PowerShell 5.1 按 GBK 解码，中文乱码甚至语法错误。
- `.vbs` 存成 **UTF-16LE（带 BOM）**，里面有中文 `MsgBox`；改成纯 ASCII 也行。
- 定位补丁点要"唯一命中"：仅用通配特征时同一个 exe 里会命中 3 处。
- 补丁的那 48 字节前面那个 `ldnull` 不属于它，一起改会 `InvalidProgramException`。

## 命令行参数

```powershell
param([string]$PclPath = '')
```

传了就跳过自动查找，直接处理指定文件；不传则走 `Find-PclExe`。
